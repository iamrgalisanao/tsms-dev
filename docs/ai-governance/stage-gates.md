# Stage Gates

This document defines the objective exit criteria for each stage of the development lifecycle.

## Stage 1: Requirement Intake
- [ ] Requirements normalized in `normalized-requirements.md`.
- [ ] All unknowns listed in `open-questions.md`.
- [ ] Assumptions registered in `assumptions-register.md`.
- **Exit Gate**: Intake Summary artifact created and approved.

## Stage 2: Tech Stack Discovery
- [ ] Backend/Frontend/Infra defined in `tech-stack-profile.md`.
- [ ] Required tools verified in `tooling-map.md`.
- **Exit Gate**: Stack Summary artifact created.

## Stage 3: Planning & Decomposition
- [ ] Tasks mapped to requirements in `task-breakdown.md`.
- [ ] Phases and milestones defined in `delivery-plan.md`.
- **Exit Gate**: Planning Summary artifact created and approved.

## Stage 4: Implementation
- [ ] Code implemented according to task-specific plan.
- [ ] Local verification evidence recorded.
- **Exit Gate**: Session Summary artifact created.

## Stage 5: Validation & Release Readiness
- [ ] Functional tests passed.
- [ ] Security review completed.
- [ ] Regression risk assessed.
- **Exit Gate**: Validation Report and Release Readiness Summary approved.
